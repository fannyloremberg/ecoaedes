## 03/11/2026 — Revisão e migração para HTML, CSS e JS puro
- Foi feita uma revisão do repositório comparando com o roteiro da 2ª entrega. Problemas encontrados: site em React (o roteiro pede HTML/CSS/JS), GitHub Pages não ativado (endereço dava 404), sem formulário, sem validação em JS, imagens faltando, 57 erros no W3C, sem pasta `docs/`.
- Decisão: **refazer o site em HTML5 + CSS3 + JavaScript puro com 10 páginas**, em uma pasta nova, sem mexer no histórico do repositório.
- Resultado: 10 páginas com 0 erros no W3C, formulário com validação e rascunho no localStorage, menu mobile, alto contraste, filtro de notícias, checklist, quiz, EcoBot, multimídia e documentação.
- **Uso de IA:** foi usado o **Grok Bot (assistente de IA)** na revisão, na migração e na documentação. O registro completo dos pedidos está em [uso_de_ia.md](uso_de_ia.md). Dois exemplos de prompt usados (versão técnica):
  1. *"Atue como revisor de Front-End. Analise o repositório github.com/fannyloremberg/ecoaedes comparando com o roteiro da 2ª entrega (anexo). Verifique HTML/W3C, CSS, JavaScript, acessibilidade, deploy no GitHub Pages, commits e documentação. Não altere nada. Entregue uma lista do que está atendido, do que falta e prints da página."*
  2. *"Refaça o site EcoAedes em HTML5, CSS3 e JavaScript puro (sem frameworks e sem build), com 10 páginas interligadas, cabeçalho/menu/rodapé iguais, validação de formulário com preventDefault, rascunho em localStorage, menu mobile com aria-expanded e alto contraste salvo. Código simples, com comentários em português. Valide no W3C até 0 erros."*
