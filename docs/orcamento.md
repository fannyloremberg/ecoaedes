| Serviço | Plano grátis | Plano pago mais barato | HTTPS | Observações |

| **GitHub Pages** | US$ 0 (incluso no GitHub Free para repositórios públicos) | — | Automático no `github.io` | Site até 1 GB; limite flexível de 100 GB/mês de banda; não deve ser usado para transações sensíveis |

## Escolha: GitHub Pages

- **Custo: US$ 0** — o site é estático (HTML, CSS e JS), não precisa de servidor.
- O código já está no GitHub; publicar é só ativar o Pages (*Settings → Pages*).
- HTTPS automático e limites muito acima do necessário (o projeto tem cerca de 1,5 MB).
- O formulário não envia dados nem recebe pagamento, o que respeita a regra do Pages de não usar o serviço para transações sensíveis.
