# EcoAedes

Site do trabalho sobre o impacto da dengue na sociedade.

Integrantes: Fabrício Oliveira da Silva, Iago Araujo da Silva Santos, Stefani Cezar Vilela e Noriel Martins Fiuza Dias.

Repositório: https://github.com/fannyloremberg/ecoaedes

## Abrir no Visual Studio Code

1. Instale o Node.js 22 ou mais novo: https://nodejs.org
2. Baixe esta pasta (Code, Download ZIP) ou clone:

```bash
git clone https://github.com/fannyloremberg/ecoaedes.git
cd ecoaedes
npm install
npm run dev
```

3. Abra o endereço que o terminal mostrar.

## Site no ar

O arquivo `.github/workflows/pages.yml` publica o site a cada envio para a branch main.

No repositório: Settings, Pages, Build and deployment, escolha GitHub Actions.

O endereço fica https://fannyloremberg.github.io/ecoaedes/
